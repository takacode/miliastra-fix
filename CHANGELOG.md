# Changelog

## 0.3.0 — 2026-10-28

- Spec-based protobuf codec (`src/protobuf.mjs`). Untouched records are still re-emitted from their original bytes.
- Read graph-variable types from each node's recorded value type. Kernels must agree with types observed in editor-saved stages (`src/kernels.mjs`, regenerated by `tools/observe-kernels.mjs`); one kernel cannot carry two types in a file.
- Classify built-in nodes structurally. Nodes that appear in messages are labelled with their official editor names, matched by pin layout; others are shown by index and type number.
- Refuse a rename when another node stores the variable's name as text. Custom-variable names are a separate namespace and do not count.
- Real stages: identical repairs, coverage, rename eligibility and patched bytes. The 7.1 runtime probe output is reproduced byte for byte. 41 regression tests.

## 0.2.0 — 2026-10-23

- Trace nested composite graph-variable references in their calling owner's scope. Add missing declarations without editing shared bodies.
- Support Entity, Item, Status and Class server owners; preserve runtime-computed names as coverage gaps.
- Add scalar initial-value editing, custom repair initial values and Float32/bounds validation.
- Add a file-wide findings view, search and filters, reference call trails, dependencies and reverse caller navigation.
- Add explicit batch review, undo/redo, before/after file comparison, saved file-bound plans, progress and cancellation.
- Strengthen type, pin, identity, mapping, recursion and scan-budget checks. Preserve unknown value/storage fields.
- Expand to 37 regression tests and full browser checks against three real stages. Independently verify eight missing-declaration warnings disappear.
- Qualify Entity scalar declaration repairs, private rename and four edited initial values in editor 7.1.0; all 13 runtime markers pass. Direct GIA import preserves the ten tested declarations. Composite/other-owner runtime and native export/reimport remain pending. Static build is ready for GitHub Pages.

## 0.1.0 — 2026-10-23

- Initial static prototype: direct server-entity graph-variable inspection, missing scalar declarations, private rename, reviewed patch plan and byte-preserving export.
- Source-generated demo, 17 tests, browser smoke checks and manual Pages workflow.
