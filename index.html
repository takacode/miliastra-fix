MILIASTRA FIX · 0.3

Understand the change.
Then make it.

Repair missing declarations, rename private variables and edit scalar initial values in server Entity, Item, Status and Class graphs.

  • Composite references are evaluated in the caller’s scope. Repairs change the owner declaration, leaving shared composite bodies intact.
  • Every finding has evidence. Runtime names, conflicting types, cycles and incomplete dependencies prevent inferred repairs.
  • Renames require exclusive direct references. Shared composite names, event listeners and names stored as text elsewhere need manual refactoring.
  • Initial values support Entity/null, Integer, Boolean, Float and String. Lists and structures are inspected without guessing their storage.
  • Batch review, undo/redo, file comparison and file-bound change plans keep larger edits manageable.
  • No uploads, accounts or analytics. Raw files remain in memory until you close or replace them.
Compatibility evidence

Editor 7.1.0 passes the Entity scalar repair, rename and initial-value runtime probe. Direct GIA import preserves the tested declarations. Shared-composite runtime, Item/Status/Class runtime and native export/reimport remain pending. See the verification notes for the exact scope.
